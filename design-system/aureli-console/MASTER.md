# AURELI 管理工作台设计规范

最新方向：Accessible & Ethical。采用 ui-ux-pro-max 的 Flat Design、焦点可见性与 Vue 指南；用户指定配色和业务工作台布局优先于搜索结果中的营销页面、默认配色建议。

## 视觉系统

- 全局：纯白背景；左下极淡灰色、右上极淡暖黄色光晕仅用于背景。所有功能面板使用平涂颜色，不使用材质渐变、阴影、三维挤出或纹理。
- 配色：蓝 #0066CC、黄 #FFBE00、黑 #101010、灰 #C5C5C5、白 #FFFFFF。正文 #101010，说明 #404040，小字号蓝色文字 #004080。错误使用语义红 #A32020，同时显示文本。
- 标题：系统无衬线，页面标题 42–64px / 900，紧凑行距 1.12；移动端 36px。业务模块标题 21–24px / 800，详情分组 16px / 800；正文 15–17px，辅助文字 12–14px。英文编号标签 12px、蓝色、全大写、2px字距。
- Dock：独立白色导航面板，2px 蓝边、16px 圆角、宽220px。选中项白底蓝边、黄色竖标、黄色数量标签；悬停由左至右滑入蓝色并切为白字；图标与文字同时出现。品牌标志使用蓝黄几何构成。
- 面板：2px 蓝边、8–12px 圆角。节点关联类型用蓝边 / 黑边、圆形 / 方形标记与文字区分；选中节点 3px 蓝边 + 有间距的4px黄环，关联按钮白底蓝边、黄色底部标记并显示“已关联”。
- 按钮：强调按钮常态白底蓝字，主按钮蓝边；悬停由左至右铺入蓝色并切为白字。黄色强调按钮铺入黄色并切为黑字，次按钮保留黑边。危险操作红色且有明确文字。普通按钮44px以上、主要按钮48px、导航56px；图标20–24px，统一Lucide SVG / 2.4px描边。
- 焦点：3px蓝色外描边、5px间距与3px黄色内环，蓝边确保白底上的可辨识度；搜索、密钥和模型来源选择将焦点呈现在完整容器上，保留原生键盘行为。
- 对比：正文 / 说明文字对白底至少7:1；主按钮白底蓝字和悬停蓝底白字达到4.5:1。视觉风格名称与参考标签不代表整个应用通过WCAG AAA认证，不在页面添加未经验证的AAA宣传标签。

## 布局和行为

- 桌面按横向画幅设计，图谱 + 详情左右双栏；主页直接呈现工作台，不放置宣传Hero、雕塑或界面示意模型。
- 所有页面、所有标题、左侧Dock、按钮、图标、表格、表单、提示、对话框和全页面视图使用同一套样式。
- 图谱平面阅读，取消立体视角切换。初始100%展示文字与操作，画布可滚动；用户可放大、缩小、主动适应画布或全页面展开。缩放会改变画布内元素的显示尺寸，不影响外部控制栏尺寸。
- 375 / 768 / 1024 / 1440 / 1920px适配；小屏折叠Dock、纵向表单，表格在独立容器中横向滚动。放大字号后允许正常纵向滚动，功能图谱在桌面首屏可见。
- 按钮悬停：CSS伪元素背景层translate3d(-101%,0,0) → translate3d(0,0,0)，所有尺寸统一320ms / linear；文字颜色320ms / ease，移入与移出使用相同的时长令牌，文字和图标不位移。退出反向恢复，可从当前值中断。精细鼠标触发；键盘聚焦和触屏按下即时显示强调色，减少动态效果设置关闭平移。禁用按钮不播放。模型来源与选中关联保留底部状态标记。
- 其余动效只保留功能性的短距离切入、节点出现与弹窗进退，使用transform / opacity并支持中断。键盘操作即时，减少动态效果设置关闭动画。无漂浮、旋转、霓虹或循环装饰。
- 原生dialog、Esc、退出后焦点恢复、异步状态与错误重试均保留。
- 数据：默认真实工作区；示例显式选择且完全本地。快照和完整回答来自后端，SSE保存确认后才标记完成。
- API：仅对话 / 向量API配置，各自支持本地与OpenAI标准来源；密钥只在后端保存。

实现：`frontend/src/style.css` 提供布局，`frontend/src/accessible.css` 提供统一视觉令牌和组件主题，`frontend/src/button-motion.css` 提供可中断的背景滑入效果。验收：`frontend/tests/accessible.smoke.mjs` 覆盖所有页面、对话框、全页面视图、对比、焦点、操作尺寸与响应式布局；其余业务回归测试继续运行。

- 图谱工作台例外：视觉上删除大型页面标题、介绍、工作区横幅与指标卡片，顶部不再保留独立操作栏；新建入口使用右侧“添加Tile”及画布操作，“导出图谱”放在工作台下方。画布高度随视口增长；页面标题保留于屏幕阅读器，其他页面仍使用编辑式标题。示例切换放在使用指南中。
